# Milestone Project 1: Static Front-End Website

## Overview
This project is a multi-page static website built using custom HTML5 and CSS3 code as part of the Diploma in Web Application Development[cite: 1, 2]. It features a responsive layout and a main navigation menu linking the Home, About, and Contact pages[cite: 2].

## Value Proposition
The website provides users with an intuitive, clean interface to discover brand details, explore core services, and easily get in touch. It solves the need for a reliable, fast-loading informational web presence.

## Features
- **Semantic HTML5 Structure**: Built using clean, accessible tags (`<header>`, `<nav>`, `<main>`, `<footer>`).
- **Custom CSS3 Styling**: Responsive design featuring custom flexbox navigation and styled containers.
- **Multi-page Navigation**: Seamless transitions across three separate dedicated pages[cite: 2].
